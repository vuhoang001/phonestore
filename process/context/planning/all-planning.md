# Planning Context

## Scope

This group covers where project plans live and how active, completed, and backlog artifacts are organized. It does not contain implementation plans itself.

## Read When

- Creating, resuming, or archiving a project plan.
- Determining whether work belongs in a feature folder or a general plan folder.

## Quick Routing

- General plans: `process/general-plans/active/`, `completed/`, and `backlog/`.
- Feature-scoped plans: `process/features/{feature}/active/`, `completed/`, and `backlog/`.
- Follow `process/development-protocols/plan-lifecycle.md` for lifecycle rules.

## Source Paths

- `process/development-protocols/plan-lifecycle.md`
- `process/development-protocols/phase-programs.md`
- `process/general-plans/`
- `process/features/`

## Update Triggers

Update this entrypoint when plan locations, naming conventions, archival rules, or feature-folder routing changes.
